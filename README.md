# my-site

Простой персональный сайт.

## Как посмотреть сайт

1. Зайди в репозиторий → **Settings** → **Pages**
2. В разделе **Source** выбери ветку `main` и папку `/ (root)`
3. Нажми **Save**
4. Через 1–2 минуты сайт будет доступен по адресу:

**https://SoftRain7.github.io/my-site/**

## Как редактировать

Открой файл `index.html` и измени текст под себя:
- имя
- описание
- ссылки

Можно редактировать прямо на GitHub (кнопка карандаша) или через код.
